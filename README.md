# homebrew-tap

Homebrew tap for Anudeep's tools.

## Fluxion

```bash
brew install --cask anudeep-gad12/tap/fluxion
```

The cask replaces any existing `/Applications/Fluxion.app` bundle and clears macOS quarantine after install.

## Spotlightify

```bash
brew install --cask anudeep-gad12/tap/spotlightify
```

The cask replaces existing `/Applications/Spotlightify.app` and `~/Applications/Spotlightify.app` bundles and clears macOS quarantine after install.
